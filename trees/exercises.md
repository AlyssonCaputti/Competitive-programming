# Trees — Exercises

Solutions go in [`python/`](python/) and [`cpp/`](cpp/).

## Easy

1. **Maximum Depth of Binary Tree** — height via DFS or BFS.
2. **Same Tree** — structural and value equality.
3. **Invert Binary Tree** — mirror left and right subtrees.

## Medium

1. **Binary Tree Level Order Traversal** — BFS by depth.
2. **Validate Binary Search Tree** — inorder or `(min, max)` bounds.
3. **Construct Binary Tree from Preorder and Inorder Traversal** — rebuild the tree.

## Hard

1. **Binary Tree Maximum Path Sum** — best path through any subtree.
2. **Serialize and Deserialize Binary Tree** — round-trip a tree to a string.
3. **Recover Binary Search Tree** — two nodes swapped — restore them in place.
