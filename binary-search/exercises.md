# Binary Search — Exercises

Solutions go in [`python/`](python/) and [`cpp/`](cpp/).

## Easy

1. **Binary Search** — classic search in a sorted array.
2. **First Bad Version** — find the first failing version via the API call.
3. **Sqrt(x)** — integer square root without floating point.

## Medium

1. **Search in Rotated Sorted Array** — find a target after a single rotation.
2. **Find Peak Element** — index where `nums[i] > neighbors` in `O(log n)`.
3. **Find First and Last Position of Element in Sorted Array** — leftmost/rightmost index.

## Hard

1. **Median of Two Sorted Arrays** — overall median in `O(log(min(m, n)))`.
2. **Split Array Largest Sum** — minimize the largest subarray sum across `k` splits.
3. **Find K-th Smallest Pair Distance** — k-th smallest `|a − b|` among all pairs.
