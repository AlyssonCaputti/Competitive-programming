# Dynamic Programming — Exercises

Solutions go in [`python/`](python/) and [`cpp/`](cpp/).

## Easy

1. **Climbing Stairs** — number of ways to reach step `n` taking 1 or 2 steps.
2. **House Robber** — max non-adjacent sum.
3. **Min Cost Climbing Stairs** — min cost to reach the top.

## Medium

1. **Longest Increasing Subsequence** — LIS length (target `O(n log n)`).
2. **Coin Change** — fewest coins to make `amount`, or `-1`.
3. **Unique Paths** — number of paths in an `m × n` grid moving right/down.

## Hard

1. **Edit Distance** — min insertions/deletions/replacements between two strings.
2. **Regular Expression Matching** — implement `.` and `*` matching.
3. **Longest Valid Parentheses** — length of the longest valid substring.
